# 🍷 Подборка хороших вин — демо на Streamlit

Веб-приложение для сомелье сервиса винной подписки (ДЗ-3, часть 4).
Модель по результатам лабораторного анализа оценивает вероятность того, что вино «хорошее»
(оценка экспертов ≥ 7), и решает, брать ли его в подборку при выбранном пороге.

**Модель:** `StandardScaler + LogisticRegression` (без весов классов), обучена на тренировочной
выборке датасета [Wine Quality](https://archive.ics.uci.edu/dataset/186/wine+quality).
**Порог по умолчанию:** 0.269 — максимизирует F1 на валидационной выборке.
Внутри приложения модель **не обучается**, только загружается из файла.

## Содержимое папки

| Файл | Что это |
|---|---|
| `app.py` | приложение |
| `model.joblib` | обученный пайплайн (scaler + логистическая регрессия) |
| `config.json` | порог по умолчанию |
| `test.csv` | тестовая выборка (12 признаков + `target`) для вкладки с метриками |
| `sample_batch.csv` | пример файла для вкладки «Пакетное предсказание» |
| `requirements.txt` | версии библиотек |

## Запуск локально

Проверено на **Python 3.9.6** (macOS). Подойдут Python 3.9–3.12.

```bash
cd wine_app
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется в браузере по адресу http://localhost:8501.

> Версия `scikit-learn` должна совпадать с той, в которой сохранялась модель (1.5.2),
> иначе `joblib.load` может выдать предупреждение или ошибку.

## Вкладки

1. **Оценка одного вина** — ввод 12 признаков (диапазоны и медианы из `test.csv`), вероятность и решение.
2. **Модельные метрики** — матрица ошибок, precision / recall / F1, ROC- и PR-кривые с точкой текущего порога; всё пересчитывается при движении слайдера в сайдбаре.
3. **Пакетное предсказание** — загрузка CSV, таблица с вероятностью и решением, скачивание результата. Порог берётся из того же слайдера (`st.session_state['threshold']`). Если в файле не хватает столбцов — понятное сообщение об ошибке.
4. **Что выучила модель** — коэффициенты логистической регрессии.

## Кэширование: почему `cache_resource` для модели и `cache_data` для таблиц

Streamlit выполняет `app.py` заново при каждом действии пользователя.

- **`st.cache_resource` — для модели.** Это «ресурс»: один объект на весь сервер, общий для всех
  сессий; Streamlit отдаёт ссылку на него, ничего не копируя. Модель мы только читаем
  (`predict_proba`), поэтому делить её безопасно. `st.cache_data` для модели не подходит — он
  при каждом обращении возвращает *копию* результата (через сериализацию pickle), т.е. модель
  всё равно распаковывалась бы на каждый перезапуск.
- **`st.cache_data` — для `test.csv`, вероятностей на тесте и точек ROC/PR-кривых.** Это «данные»:
  результат зависит только от аргументов, каждый вызов получает свою копию, так что случайное
  изменение DataFrame в одном месте не испортит кэш. Вероятности на тесте считаются один раз —
  при движении слайдера меняется только сравнение `proba >= threshold`, а `predict_proba` заново не
  вызывается. Аргумент `_model` в `test_proba(_model, X)` начинается с подчёркивания, чтобы Streamlit
  не пытался хешировать модель.
- **Что будет без декоратора у `joblib.load`:** модель будет заново читаться с диска и
  десериализоваться при *каждом* действии пользователя (каждом сдвиге слайдера, вводе числа).
  Приложение станет медленнее (для больших моделей — секунды на каждое действие), будет лишняя
  нагрузка на диск и память, а при многих пользователях — по копии модели на каждый перезапуск.

## Деплой на Streamlit Community Cloud

1. Залейте папку `wine_app/` в публичный репозиторий на GitHub (вместе с `model.joblib`, `config.json`, `test.csv`).
2. Зайдите на [share.streamlit.io](https://share.streamlit.io) → **Create app** → *Deploy a public app from GitHub*.
3. Укажите репозиторий, ветку и путь к файлу: `wine_app/app.py`
   (`requirements.txt` лежит рядом с `app.py`, Streamlit найдёт его сам).
4. В **Advanced settings** выберите Python **3.11** или **3.12** (для `numpy==1.26.4` нет сборок под 3.13).
5. Нажмите **Deploy** и вставьте полученную ссылку `https://<имя>.streamlit.app` в ноутбук.
